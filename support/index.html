Quick help

  • Change location — tap the pin on Today, or Settings → Location.
  • Units — Settings → Units (Metric / UK / Imperial).
  • Models disagree — the app shows spread and still uses a weighted consensus; learning improves weights after a few days of actuals.
  • Radar — Sky above → Radar for precipitation; Play loops past frames. Clouds is a single model field snapshot.
  • Offline — last successful forecast is shown when the network fails; pull to refresh when back online.
  • Alerts (desktop) — morning brief / rain soon use a background worker on Windows/Mac desktop. iOS closed-app alerts need a later native build.

Data sources

Forecasts and geocoding: Open-Meteo. Radar composites: RainViewer public API. Not an official meteorological or emergency service.
